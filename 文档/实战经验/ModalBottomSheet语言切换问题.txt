ModalBottomSheet 语言切换不生效与弹窗重启

场景：Activity 层通过 CompositionLocalProvider(LocalContext provides localizedContext) 实现应用内语言切换后，普通 Compose 内容能正确显示新语言，但 ModalBottomSheet 内的文字仍保持旧语言；早期 workaround 是在 ViewModel 里先关闭再打开弹窗，导致切换语言时弹窗重启。

根因：ModalBottomSheet 内部会创建独立的 Dialog/Window（ModalBottomSheetDialogWrapper），其 Context 为 ContextThemeWrapper(composeView.context)。该 Dialog 拥有自己的 AbstractComposeView，并在根节点重新提供 LocalContext，从而覆盖了外部注入的本地化上下文，使 stringResource 仍读取旧资源。

处理方案：
（1）在 SettingsSheet 进入 ModalBottomSheet 前捕获外部已本地化的上下文，并在 sheet 内容区重新注入 LocalContext 与 LocalConfiguration：
    val localizedContext = LocalContext.current
    val localizedConfiguration = localizedContext.resources.configuration

    ModalBottomSheet(...) {
        CompositionLocalProvider(
            LocalContext provides localizedContext,
            LocalConfiguration provides localizedConfiguration,
        ) {
            // sheet content
        }
    }
（2）移除 ViewModel 中切换语言时强制关闭/打开弹窗的 workaround，弹窗会随 localizedContext 变化原地重组，无需重启。

涉及源码参考：androidx.compose.material3.ModalBottomSheet.android 中的 ModalBottomSheetDialogWrapper / ModalBottomSheetDialogLayout。
